Eu apresentei uma API ao vivo pra uma banca, sem saber se ela ia resistir a uma pergunta.

Isso foi na seleção de trainee, antes de qualquer emprego formal como dev.

O processo tinha várias etapas eliminatórias.

Lógica de programação. Depois um desafio em console. Depois APIs.

A etapa final foi o desafio de verdade: construir uma API REST de locadora de veículos, usando Clean Architecture, e apresentar o resultado ao vivo pra uma banca.

Clean Architecture, pra quem não viu ainda, é separar o núcleo de regras de negócio de detalhes como banco de dados ou framework web, em camadas que não dependem das camadas de fora.

Eu nunca tinha apresentado código pra ninguém decidir se eu passava ou não.

Na apresentação, a banca não queria só ver a tela funcionando.

Queria entender por que cada camada existia, da Controller até o Repository, e o que quebraria se eu removesse uma delas.

Eu passei.

O que ficou não foi a API em si.

Foi perceber que estrutura sem motivo não convence ninguém numa sala, muito menos uma pessoa querendo ver se eu sei o que fiz, ou só copiei um tutorial.

Você já teve que defender uma decisão de arquitetura na cara de alguém, em tempo real, sem slide pra esconder atrás?
